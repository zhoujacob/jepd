# Working on this repository

This is a web app for the University of Waterloo Pickleball Club.
Read docs/PROJECT.md before implementing a new feature.

- Keep changes small and understandable for future student maintainers.
- Use Next.js, TypeScript, and Supabase.
- Check exec/admin permissions on the server for protected actions.
- Never commit credentials or real participant information.
- Do not collect or store student ID images.
- Add database changes as migrations.
- Run lint and build before finishing a coding task.
- Update the README when setup steps change.
